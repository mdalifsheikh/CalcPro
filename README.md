# CalcPro 🧮

**Beautiful Flutter Calculator App**

A clean, modern calculator built with Flutter + Dart.  
Designed to be built **entirely on GitHub Actions** — no local computer needed!

---

## Features

- Clean dark Material 3 UI
- Basic operations: `+ − × ÷ %`
- Clear, Backspace, Decimal support
- Expression evaluation with `math_expressions`
- Responsive portrait layout

---

## How to get the APK (No PC needed)

1. Go to the **Actions** tab of this repository
2. Select **Build CalcPro APK**
3. Click **Run workflow**
4. Wait 3–6 minutes
5. Download the **CalcPro-APK** artifact
6. Install the `.apk` on your Android phone
